# 仮想環境の依存関係トラブルシューティング

## 概要

`start_jetracer.sh` 実行時に発生した依存関係エラーとその解決方法をまとめた技術資料。

**発生日**: 2024年12月6日
**環境**: Jetson Orin Nano / JetPack 5.x / Python 3.10

---

## 発生した問題

### 症状

```bash
$ bash start_jetracer.sh
ModuleNotFoundError: No module named 'typing_extensions'
```

その後、複数の依存関係エラーが連鎖的に発生。

---

## 原因分析

### 1. Python パッケージの欠落

仮想環境 (`.venv`) に必要なパッケージがインストールされていなかった。

| パッケージ | 役割 |
|-----------|------|
| `typing_extensions` | Python 型ヒント拡張（niceguiの依存） |
| `traitlets` | JetCam の依存パッケージ |
| `pyyaml` | 設定ファイル読み込み |
| `psutil` | パフォーマンスモニタリング |
| その他 nicegui/fastapi 関連 | Web UI フレームワーク |

### 2. JetCam のインストール方法

`jetcam` は PyPI に公開されていないため、通常の `pip install` では失敗する。

```
ERROR: No matching distribution found for jetcam>=0.0.0
```

### 3. GStreamer バインディング (PyGObject) の問題

仮想環境では、システムにインストールされた `python3-gi` (GObject Introspection) にアクセスできない。

```
[Camera] PyGObject/GStreamer not available; cannot start fallback pipeline
```

---

## 解決手順

### Step 1: 基本パッケージのインストール

```bash
source .venv/bin/activate

# typing_extensions（最初に発生したエラー）
pip install typing_extensions

# requirements.txt の依存関係（jetcam以外）
pip install "numpy<2.0" "opencv-python-headless==4.8.1.78" pyyaml \
    "nicegui==1.4.33" "fastapi==0.109.1" "uvicorn[standard]==0.27.0" psutil

# JetCam の依存パッケージ
pip install traitlets
```

### Step 2: JetCam のインストール

GitHub リポジトリから直接インストールする。

```bash
pip install git+https://github.com/NVIDIA-AI-IOT/jetcam.git
```

### Step 3: GStreamer バインディングの有効化

システムの `python3-gi` を仮想環境から参照できるようにシンボリックリンクを作成。

```bash
# システムに python3-gi がインストールされているか確認
dpkg -l | grep python3-gi

# シンボリックリンクの作成
ln -sf /usr/lib/python3/dist-packages/gi .venv/lib/python3.10/site-packages/
ln -sf /usr/lib/python3/dist-packages/cairo .venv/lib/python3.10/site-packages/

# 動作確認
source .venv/bin/activate
python3 -c "import gi; gi.require_version('Gst', '1.0'); from gi.repository import Gst; print('OK')"
```

## 補足情報

### CSICamera vs GStreamer Fallback

| 方式 | 説明 | 状態 |
|-----|------|-----|
| CSICamera (JetCam) | OpenCV ベースの直接アクセス | 失敗することがある |
| GStreamer Fallback | nvarguscamerasrc パイプライン | 安定動作 |

現在の実装では、CSICamera が失敗した場合に自動的に GStreamer Fallback に切り替わる。

### requirements.txt の改善案

現在の `requirements.txt` には `jetcam>=0.0.0` が含まれているが、PyPI からはインストールできない。以下のいずれかの対応を検討：

1. コメントで GitHub からのインストール方法を記載
2. `setup.py` または `pyproject.toml` で dependency_links を設定
3. インストールスクリプトを用意
